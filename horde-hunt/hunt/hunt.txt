# Horde Hunt source. This file stays OFF stream: it holds the answers.
# compile.py hashes the answers and the door code. Neither ships in plain text.
#
#   hunt: <name>            name of the hunt
#   door: <petal-id>        florra.net petal the door code opens (bounty-sounds, redstring, ...)
#   code: <word>            the door code, given out when the last clue is found
#   = <id> | <title>        a clue card (ids: short, unique, never reused)
#   ? <riddle>              what chat sees on the board (several ? lines join up)
#   @ <zone> | <x> <y> [r]  verify: player stands within r map-% of x,y in zone (default r 1.0)
#   $ <item name>           verify: the item is looted
#   > <npc name>            verify: player talks to the npc
#   ! manual                verify: Max types /hunt done
#   a <answer> | <alt>      what chat must type after !clue to solve it
#   b <n>                   Desk Bucks to the solver once the find is verified (default 100)
#   w <n>                   purse weight for the bounty draft (default 1)
#   s <text>                the red string: why this clue leads to the next
#
